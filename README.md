# Netnám Tónsmiðju Suðurlands

Drög að vefsíðu fyrir netnám Tónsmiðju Suðurlands: kennsla á myndbandi, æfing heima, upptökur og endurgjöf frá kennara.

Þetta er sýnishorn. Innskráning, upptökur og skilaboð eru ekki tengd netþjóni.

- `index.html` – forsíða
- `piano.html` – píanó: 15 námskeið á 4 getustigum
- `namskeid.js` – námskeiðaskráin (breyttu námskeiðum hér)
- `hvernig.html` – hvernig netnámið virkar
- `verd.html` – verð
- `spurningar.html` – algengar spurningar
- `nemandi.html` – svæði nemanda (sýnishorn)
- `skilabod.html` – samtal við kennara (sýnishorn)
- `innskraning.html` – innskráning: veldu notanda (Stefán, Eyþór eða nemandi)
- `kennari.html` – kennarasvæði (sýnishorn)

> Innskráningin er eingöngu til sýnis og veitir enga raunverulega vörn.
